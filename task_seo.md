# Dandiya Connect Pune 2026 - SEO & Expansion Plan

This document outlines the strategic roadmap for expanding the Dandiya Connect Pune 2026 website. The goal is to build a robust, interconnected web presence that captures organic search traffic across both B2C (attendees/ticket sales) and B2B (sponsors/partners/vendors) funnels.

## 1. SEO Targeting & Strategy

We will build 8-10 dedicated pages that route back to the main event page and cross-link with each other. The main landing page will remain the primary hub for traffic and conversions. The supporting pages will target specific search intents to capture organic traffic:

### Target Keywords & Search Intents
*   **B2C (Ticket Sales & Attendees):**
    *   `dandiya pass pune 2026` -> **Tickets Page** (`tickets.html`)
    *   `navratri events pune` -> **Main Page / Blog 1** (`navratri-events-pune.html`)
    *   `dandiya night near me pune` -> **Venue Page** (`venue.html`)
    *   `best dandiya events pune 2026` -> **Highlights / Blog 2** (`best-dandiya-events-pune-2026.html`)
*   **B2B (Partnerships & Corporate):**
    *   `sponsor navratri event pune` -> **Sponsorship Page** (`sponsorship.html`)
    *   `food stall dandiya event pune` -> **Vendors Page** (`food-stalls-vendors.html`)
    *   `perform at dandiya event pune` -> **Performers Page** (`performers-artists.html`)
    *   `corporate dandiya night pune` -> **Corporate Bookings Page** (`corporate-bookings.html`)

## 4. Pending Client Questions (Blockers)

Before populating full final production copy, we need the following details from the client:

1. **Pricing Details:**
   - Final ticket pricing and tiers (Early bird, VIP, General).
   - Sponsorship tier pricing and deliverables.
2. **Event Details:**
   - Real venue address and dates.
3. **Historical Context:**
   - Is this the first year of the event? If not, do we have past photos, attendee stats, or testimonials to use for social proof?
4. **Current Relationships:**
   - Are there any current or confirmed sponsors/partners we need to feature immediately?
